## 中文

为 *Sekiro: Shadows Die Twice* 的 mod：[Malevolence](https://www.nexusmods.com/sekiro/mods/1819) 提供的简体中文语言包。

### 安装

1. 解压后把 `msg` 文件夹复制进 `...\mods\`（已有同名文件先备份）。
2. 标题画面 → `Language` → `Text` → 简体中文 → 重启游戏。

   这里只列举一种安装方式，你也可以使用：
- [Sekiro ME](https://www.nexusmods.com/sekiro/mods/6)
- [ME3](https://github.com/garyttierney/me3)


### 已知限制

1. 英文包另有 4 张表在中文包里缺失（`メニュー共通テキスト`、`メニューその他`、`項目ヘルプ`、
   `テキスト表示用タグ一覧`），内容为 Dark Souls 3 遗留文本；mod 未改动，官方简中同样没有，
   中文客户端不读取，对显示无影响。
2. 说明文的分段沿用官方简中；部分条目的中文段落空行比英文少，官方文本本身如此。

### 目录

```
msg/zhocn/item.msgbnd.dcx   道具/招式/敌人等文本
msg/zhocn/menu.msgbnd.dcx   菜单、对白、字幕等文本
```

### 声明

- 译文为 AI 辅助并统一术语。报错请附表名、条目 id 与截图。无需完整提供；提供其他内容也可以。

## English

Simplified Chinese language pack for the *Sekiro: Shadows Die Twice* mod: [Malevolence](https://www.nexusmods.com/sekiro/mods/1819)

### Installation

1. Unzip and copy the `msg` folder into `...\mods\` (back up any files it replaces).
2. Title screen → `Language` → `Text` → Simplified Chinese → restart.

   Only one method is listed here, you can also use these: 
- [Sekiro ME](https://www.nexusmods.com/sekiro/mods/6)
- [ME3](https://github.com/garyttierney/me3)


### Known limitations

1. Four tables present in the English bundle are absent from both the Chinese one and the official
   Chinese localization (`メニュー共通テキスト`, `メニューその他`, `項目ヘルプ`, `テキスト表示用タグ一覧`);
   they hold Dark Souls 3 leftovers, untouched by the mod and never read by the Chinese client.
2. Chinese paragraph breaks follow the official CN text; some entries keep fewer blank lines than the
   English version, exactly as the official localization does.
   
   Only one method is listed here.
### Layout

```
msg/zhocn/item.msgbnd.dcx   items, Combat Arts, enemies
msg/zhocn/menu.msgbnd.dcx   menus, dialogue, subtitles
```

### Notes

- Translations were produced with AI assistance and reviewed for terminology consistency.
- If you encounter any issues, please report them with the table name, entry ID, and a screenshot. You do not need to provide a complete report; any relevant information is helpful.
